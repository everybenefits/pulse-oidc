# @everybenefits/oidc

Pulse shared package published to GitHub Packages as scoped `@everybenefits/*`.

## Install

```ini
# .npmrc
@everybenefits:registry=https://npm.pkg.github.com
//npm.pkg.github.com/:_authToken=${NODE_AUTH_TOKEN}
```

```bash
pnpm add @everybenefits/oidc@^0.1.0
```

## Publish

Tag `v*` triggers GitHub Actions publish to GitHub Packages.
